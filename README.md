# 🎟️ Insight Pass 回本計數機

專為百老匯電影中心 **Insight Pass** 會員設計嘅免費觀影紀錄與回本進度計算工具。

👉 **即刻用**：[https://ricky-lk.github.io/insight-pass-calculator](https://ricky-lk.github.io/insight-pass-calculator)

**目前版本：v1.0.6｜資料最後更新：2026/10/18**

---

## 🌟 主要功能

- 📊 **回本進度估算**：即時計算目前已回收金額、回本百分比及仲差幾多張戲飛回本。
- 🎬 **智能票價建議**：按觀看日期及票種套用票價。2026-09-10 起成人正價 $100；小童／學生及長者平日 $75、週末及公眾假期 $80；成人非公眾假期星期二 $80；早場 $60。生效日前的場次沿用舊票價。
- 🕒 **彈性記錄日期**：購買日期必填，購買及觀看時間選填；可在設定中隱藏時間欄位。沒有觀看時間時，票價建議會按一般場次計算。
- 🔒 **本地私隱儲存**：所有觀影紀錄只會儲存在你自己的手機／電腦瀏覽器內，絕不上傳伺服器。
- 📦 **年度封存與備份**：支援舊年度紀錄封存，並可隨時匯出／匯入 JSON 備份檔案。

## 📱 加入手機主畫面（全螢幕 App 體驗）

- **iPhone (Safari)**：點擊底部的「分享」按鈕 ➔ 選擇「加入主畫面」。
- **Android (Chrome)**：點擊右上角「三個點」選單 ➔ 選擇「安裝應用程式」或「新增至主螢幕」。
